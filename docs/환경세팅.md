# 환경 세팅 (수업 · 집 · 회사)

목표: 어느 PC에서든 이 저장소를 clone하면 실습을 이어갈 수 있게 한다.

## 필수

| 항목 | 권장 | 확인 명령 |
|------|------|-----------|
| Git | 최신 | `git --version` |
| Python | 3.11 | `python --version` |
| 가상환경 | venv | `.\.venv\Scripts\Activate.ps1` |
| GitHub 계정 | SIJackLee | `gh auth status` |

### Windows 설치 예시 (winget)

```powershell
winget install --id Git.Git -e
winget install --id Python.Python.3.11 -e
winget install --id GitHub.cli -e
```

설치 후 **터미널을 다시 열고** PATH가 반영됐는지 확인합니다.

### Python 패키지

```powershell
cd AI-IoT
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install -r requirements-ml.txt
pip install -r requirements-dl.txt
pip install platformio
```

| 파일 | 내용 |
|------|------|
| `requirements.txt` | 기초 (numpy, pandas, sklearn, MQTT) |
| `requirements-ml.txt` | Jupyter, seaborn 등 ML 실습 |
| `requirements-dl.txt` | TensorFlow, PyTorch (CPU, 이식성 우선) |

#### 검증

```powershell
python -c "import sklearn, tensorflow as tf, torch; print(sklearn.__version__, tf.__version__, torch.__version__, torch.cuda.is_available())"
pio --version
```

#### GPU (선택, 이 PC는 RTX 5070)

- Windows 기본 TensorFlow 휠은 CPU입니다.
- PyTorch CUDA는 PC마다 드라이버가 달라 **requirements에는 CPU를 고정**했습니다.
- GPU 토치가 필요하면 해당 PC에서 [PyTorch Get Started](https://pytorch.org/get-started/locally/) 안내로 별도 설치하세요.

## 펌웨어 (PlatformIO + Cursor)

1. **CLI** (필수): 위 `pip install platformio` 후 `pio --version`
2. **Cursor 확장** (권장): Extensions에서 `PlatformIO IDE` 검색 후 설치  
   - Cursor 마켓에 없으면 VS Code용 VSIX를 받아 `cursor --install-extension <파일.vsix>` 로 설치
3. 프로젝트: `firmware/` (`platformio.ini`, `src/main.cpp`)

```powershell
cd firmware
pio run -e uno          # Arduino Uno 빌드
pio run -e esp32dev     # ESP32 빌드 (보드 있을 때)
pio run -e uno -t upload
pio device monitor -b 9600
```

## 실습 단계별

| 단계 | 도구 | 비고 |
|------|------|------|
| MCU 펌웨어 | PlatformIO (`firmware/`) | Cursor 터미널 또는 PIO 확장 |
| 레거시 스케치 | `arduino/` | 필요 시 Arduino IDE |
| SBC | Raspberry Pi Imager | 보드가 있을 때 |
| MQTT | Mosquitto 또는 공개 테스트 브로커 | 수업 서버에만 의존하지 않기 |
| 시뮬 | MATLAB Simulink | 기관 라이선스 확인. 없으면 Python PID 대체 |
| 무거운 AI | 로컬 DL 또는 Google Colab | 회사 PC 제한 시 Colab |

## 비밀값

1. `.env.example`을 복사해 `.env` 작성
2. `.env`는 `.gitignore`로 제외됨
3. MQTT 비밀번호, API Key 등을 `.env`에만 보관

## PC 복제 체크리스트

- [ ] Git / Python 3.11 설치
- [ ] `git clone https://github.com/SIJackLee/AI-IoT.git`
- [ ] venv + `requirements.txt` / `requirements-ml.txt` / `requirements-dl.txt` / `platformio`
- [ ] Cursor에 PlatformIO IDE 확장 (가능하면)
- [ ] `.env` 작성
- [ ] `python -c "import sklearn, tensorflow, torch; print('dl ok')"`

## 롤백

- 가상환경: `.venv` 폴더 삭제 후 재생성
- PlatformIO 툴체인: `%USERPROFILE%\.platformio` 삭제 (재다운로드됨)
- winget 앱: Windows 설정 → 앱 → 제거
