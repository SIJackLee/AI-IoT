# 환경 세팅 (수업 · 집 · 회사)

목표: 어느 PC에서든 이 저장소를 clone하면 실습을 이어갈 수 있게 한다.

## 필수

| 항목 | 권장 | 확인 명령 |
|------|------|-----------|
| Git | 최신 | `git --version` |
| Python | 3.11 | `python --version` |
| 가상환경 | venv | `.\.venv\Scripts\Activate.ps1` |
| GitHub 계정 | SIJackLee | `gh auth status` |

### Windows 설치 예시 (winget)

```powershell
winget install --id Git.Git -e
winget install --id Python.Python.3.11 -e
winget install --id GitHub.cli -e
```

설치 후 **터미널을 다시 열고** PATH가 반영됐는지 확인합니다.

### Python 패키지

```powershell
cd AI-IoT
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

TensorFlow / PyTorch는 용량이 크므로 **수업에서 지정한 쪽만** 나중에 추가합니다.

## 실습 단계별 (필요할 때)

| 단계 | 도구 | 비고 |
|------|------|------|
| MCU | Arduino IDE | `arduino/` 스케치 업로드 |
| SBC | Raspberry Pi Imager | 보드가 있을 때 |
| MQTT | Mosquitto 또는 공개 테스트 브로커 | 수업 서버에만 의존하지 않기 |
| 시뮬 | MATLAB Simulink | 기관 라이선스 확인. 집/회사 없으면 Python PID로 대체 가능 |
| 무거운 AI | Google Colab | 회사 PC 사양·정책 제한 시 |

## 비밀값

1. `.env.example`을 복사해 `.env` 작성
2. `.env`는 `.gitignore`로 제외됨
3. MQTT 비밀번호, API Key 등을 `.env`에만 보관

## PC 복제 체크리스트

- [ ] Git / Python 3.11 설치
- [ ] `git clone https://github.com/SIJackLee/AI-IoT.git`
- [ ] `python -m venv .venv` + `pip install -r requirements.txt`
- [ ] `.env` 작성
- [ ] `python -c "import numpy, pandas, sklearn, paho.mqtt; print('ok')"`

## 롤백

- 가상환경: `.venv` 폴더 삭제 후 재생성
- winget 앱: Windows 설정 → 앱 → 제거
