# Wi-Fi · 원격 대시보드 연동 탐색

## 칩 Wi-Fi 특성 (실측)

- 보드: ESP32-WROOM-32E (MGN4) / ESP32-D0WD-V3
- Features: **Wi-Fi + BT**, Dual Core, 240MHz
- STA MAC: (시리얼 스캔 로그 참고)
- SoftAP / Station 모드 지원
- HTTP Client/Server, MQTT(PubSubClient 이미 deps), WebSocket 가능

## Vercel / 앱 연동 결론

**가능함.** 다만 ESP32가 Vercel에 “직접 상주”하는 구조는 아님.

| 방식 | 가능 | 비고 |
|------|------|------|
| A. ESP32 SoftAP + 로컬 웹 | ✅ | 같은 Wi-Fi/핫스팟, 인터넷·Vercel 불필요 |
| B. ESP32 STA → MQTT → Vercel 대시보드 | ✅ **추천** | HiveMQ 등 브로커, 브라우저 mqtt.js(WSS) |
| C. ESP32 → Supabase/API → Vercel UI | ✅ | REST/Realtime, 원격제어에 적합 |
| D. ESP32 ↔ Vercel Function 장시간 WS | ⚠️ | 서버리스 한계, Redis 등 부가 필요 |
| E. 네이티브 앱(Flutter/RN) | ✅ | B/C와 동일 백엔드 사용 |

권장(연수·집·회사): **B 또는 C**
`센서/제어(ESP32) → MQTT 또는 Supabase → Vercel(Next.js) 대시보드`
